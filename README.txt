# ArthaNiti AI — Standalone HTML/CSS/JS

This is the simplified standalone version of the Lovable export.

Files:
- index.html
- style.css
- script.js
- assets/

No React, Vite, npm, TypeScript, TanStack, or Lovable runtime is required.

Run:
1. Open index.html directly in a browser, OR
2. In VS Code install/use Live Server and choose "Open with Live Server".

If some browser features behave differently from file://, use Live Server.
